# Futuristic araştırma atlası

Türkçe karar raporu. Altı kullanıcı belgesinin sentezi; orijinaller ve referanslar kayıpsız arşivlenir. Belgelerdeki talimat örnekleri uygulamaya yönelik talimat değildir.

- React + TypeScript + Vite, Tailwind CSS + daisyUI; statik GitHub Pages.
- Mobilde alt gezinme, bölüm seçici alt panel, kısa özet ve açılabilir derinlik; masaüstünde kalıcı içindekiler ve yan yana karşılaştırma.
- 48px dokunma hedefleri, görünür klavye odağı, kaçışla kapanan ve odağı geri veren native dialog, reduced motion, safe-area.
- Kaynak ID'si ile sentezden orijinale iz; tarihli doğrulama kaydı. Çözülemeyen eski atıf tokenları için URL uydurulmaz.
- Türkçe/ASCII uyumlu başlık ve tam metin arama; kalıcı okundu ve yol haritası listeleri. Depolama engeli uygulamayı bozamaz.
- Maliyetler kullanıcı kontrollü senaryodur; güncel teklif gibi sunulmaz.
- TDD: davranış testleri önce başarısız; minimal uygulama; typecheck, build, mobil/masaüstü tarayıcı ve erişilebilirlik kontrolleri.
- Gerçek video üretimi, sosyal hesap bağlantısı ve backend yoktur. Portal araştırma ve karar aracıdır.
